# 2026-11-04 電子ドラム改善と生キット分離

依頼の対象は電子ドラム。前回の生ドラムV2を元セットの上書きではなく選択肢studioV2として追加。studioは旧素材・旧強弱補正を復元。既存の共通ミキサー処理は維持。

電子全11パーツを調整。キック/スネア/タムの過大なピッチスイープを縮小、発音時間を秒指定にしてBPM依存を除去。リムに三角波、ハット/クラッシュに金属合成成分を追加。ライドのベル音を調整。クラップは3連エンベロープに変更。閉ハットで開ハットをチョーク。velocity<=0/非有限値は無音。バスコンプを2:1・20msに変更。

検査: TypeScript本番ビルド・対象eslint・既存8テスト合格。ブラウザ実エンジンで電子全11パーツの弱/中/強/連打+合奏47秒を生成、peak -12.06dBFS、クリップなし。元の生キットも47秒生成成功、peak -12.44dBFS。人間による聴感評価は未完了であり、プロ音質を保証しない。
