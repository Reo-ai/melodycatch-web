# ドラム追加検証 — 2026-11-04 JST

対象: main 4854e7a + この検証で追加した未コミット修正。

## 結論

電子ドラムの発音制御と生ドラム切替に回帰テストを追加。旧サンプルキットの遅延ロード完了・失敗コールバックが、切替後のキット状態を変更する race を修正した。push・本番デプロイはこの検証担当では実施していない。

## 確認内容

- 電子ドラム11パーツそれぞれが発音をスケジュールする。
- 電子キック・スネア・閉ハットを同時刻に指定した場合、同一時刻で各発音部へ渡る。
- 0・負数・NaN・Infinity の velocity では電子音源を初期化せず発音もしない。1超は上限1に収まる。
- 電子閉ハットが、開ハットのノイズ・金属音の両方へ指定時刻の release を渡す。
- Studio の閉ハットが開ハットのサンプル source を停止する。
- Studio Original → V2 の古いロード完了は、現キットを読み込み済み扱いにしない。
- 旧キット → Studio、および旧キット間切替でも、古い onload/onerror を世代番号で無効化する（今回の修正）。
- 電子出力コンプレッサーは共通ミキサーへ接続。生ドラムも getReverbInput によりフェーダー後から残響へ送る構成であることをソース確認。

## 検証方法と限界

`node --experimental-strip-types --test tests/*.test.mjs`。追加テストは実エンジンのTypeScriptをtranspileし、Toneノードをモック化して呼び出し・状態遷移を検査する。PCM音量、実ブラウザの同音連打制約、ミュート後の残響減衰、音質の良し悪しをこれらのテストだけで証明していない。

`npm run build` 成功。既存の500KB超chunk警告、Browserslistデータ更新案内あり。

iPhone実機の新電子ドラム音質・密集連打・バックグラウンド復帰は今回未検証。過去のユーザー確認（消音モードで鍵盤・再生が鳴る）とは区別する。新しいキットの人間による聴感確認を完了したとは扱わない。

## 同日追加修正：読み込み失敗の再試行

旧キット・Studioとも読み込み失敗後の同一キット再選択で再取得できるよう修正。選択中ボタンの再クリックも音源処理へ渡す。正常時・エラー前の読込中は重複取得しない。古い世代の失敗通知は新しい読み込み状態を変更しない。追加2テストを含む16テスト合格。iPhone実機試験は未実施。
