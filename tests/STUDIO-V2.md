# 生ドラム全体改修（2026-11-04）

76録音を原FLACから再生成。対象はキック、スネア、リム、クローズ/オープンハット、クラッシュ、ライド、高/低タム。中タムは低タムのピッチ変換を維持。クラップは既存素材を維持。

楽器群ごとにマイクを選び、同じ比率で全マイクを足す処理をやめた。全録音192kbps MP3。音量基準はマイクの収録ゲインに依存させず、楽器別に固定。各層2録音を交互使用。スネア等の近接強弱録音は、本来の同一強度ラウンドロビンとは区別する。

検査: 8単体テスト、対象TypeScript eslint、production build合格。76音源のデコード成功・原音クリップなし。tests/drum-kit-review.htmlで実エンジンから全パーツの弱/中/強/連打と合奏44秒を生成成功。peak -12.42dBFS、クリップなし。

人間による聴感採点、iPhone新キット全パーツ試聴は未完了。「完璧」「プロ音質保証」とはしない。音源総量7.6MB（旧キットはロールバック用に保持）。既存依存関係のnpm auditは22件で、今回無関係な破壊的更新はしていない。

再生成: node scripts/build-studio-v2.mjs。ネット接続・gh・ffmpegが必要。生成時の原音コミットはprovenance.jsonに固定記録。
